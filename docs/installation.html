LightSuite Neuroglancer

Installation and usage guide: view LightSuite atlas-registration results (sample channels, warped atlas, region names, statistics and 3D meshes) in Neuroglancer on Windows, Linux or macOS.

1. Requirements

  • Windows 10/11, Linux or macOS. No administrator rights needed.
  • uv, a small Python manager. It downloads Python 3.10+ and all dependencies by itself, so you do not need Python, conda or pip.
  • Internet on the first run only, to download the dependencies (about 150 MB).
  • A browser with WebGL 2: a recent Chrome, Edge or Firefox.
  • 3–4 GB free disk per brain for the converted data, and 8 GB+ RAM for the first conversion of a 20 µm brain.

2. Install uv (once per PC)

Windows (PowerShell)

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

Linux / macOS

curl -LsSf https://astral.sh/uv/install.sh | sh

Then close and reopen the terminal and check it with uv --version.

If you can't use the installer (e.g. company policy), pip install uv or conda install -c conda-forge uv also work. You can also skip uv and use pip directly, see option C below.

3. Get the tool

Choose one of the following options:

A. Run from the folder

No installation. Best if you might edit the code.

B. Install as a command

Adds lightsuite-neuroglancer to your PATH. Run it from any folder.

C. pip / conda env

Install into an existing Python environment.

A. Run from the folder (no install)

Download the code with git, or download the ZIP from GitHub and extract it, for example to D:\LIGHTSUITE\lightsuite-neuroglancer:

git clone https://github.com/YCabara/lightsuite_neuroglancer.git D:\LIGHTSUITE\lightsuite-neuroglancer
cd D:\LIGHTSUITE\lightsuite-neuroglancer
uv run view_in_neuroglancer.py

On Windows you can also just double-click run_viewer.bat (a folder picker opens), or drag a results folder onto it.

B. Install as a command (recommended for regular users)

# from GitHub
uv tool install git+https://github.com/YCabara/lightsuite_neuroglancer.git

# or from a local copy of the folder
uv tool install D:\LIGHTSUITE\lightsuite-neuroglancer

Then, from any terminal:

lightsuite-neuroglancer D:\brain8_analysed\8_DNF_atlased

If the command is not found, run uv tool update-shell once and reopen the terminal.

C. Into a pip or conda environment

conda create -n lsng python=3.12 -y
conda activate lsng
pip install D:\LIGHTSUITE\lightsuite-neuroglancer      # or: pip install git+https://github.com/YCabara/lightsuite_neuroglancer.git
lightsuite-neuroglancer --version

4. Open a dataset

Pass the registration output folder. This is the folder that contains volume_registered\sample_space\sample_space_manifest.json, or any folder above it. If several results are found under it, you are asked to choose one.

lightsuite-neuroglancer D:\brain8_analysed\8_DNF_atlased
:: or, without installing (option A):
uv run view_in_neuroglancer.py D:\brain8_analysed\8_DNF_atlased

Without a folder, a folder picker opens.

  1. First run: the data is converted to Neuroglancer format in <results>\neuroglancer\. This takes a few minutes, mostly building 3D meshes (use --no-meshes to skip them). Expect output like: 
    Converting D:\brain8_analysed\8_DNF_atlased -> D:\brain8_analysed\8_DNF_atlased\neuroglancer
  grid (331, 671, 671) (x,y,z), voxel [20.0, 20.0, 20.0] um, channels ['ch1', 'ch2']
  region names from: sample stats/region_stats.csv
  level 'regions': 615 regions
  ...
  building region meshes (949 regions) ...
  region centres (for search) ...
Viewer (with region search and channel LUTs): http://127.0.0.1:50893/lightsuite/
Plain Neuroglancer: http://127.0.0.1:50894/v/5f41.../
Press Ctrl+C to stop.
  2. The browser opens on the viewer, with the side panel for region search and channel LUTs. Keep the terminal open while you use it, because it serves the data.
  3. Stop with Ctrl+C in the terminal (or close the window).
  4. Later runs reuse the converted data and start in seconds. It is rebuilt automatically when the registration files or the tool change. Use --reexport to force a rebuild.

5. Command-line options

6. Using the viewer

Layers

LayerContent
ch1, ch2, …Sample channels on the registration grid (ch2+ hidden and coloured).
templateAtlas template warped onto the sample (hidden).
boundariesAtlas region outlines.
hierarchy levelsOne layer per level, e.g. regions, structure, division.
extra labelsE.g. division_labels, spinal-cord segments (hidden).
region meshes3D surface of every region at every level.

Side panel: find a region

The browser opens on http://127.0.0.1:<port>/lightsuite/, which is Neuroglancer with a panel on the left (hide it with ‹, bring it back with the tab on the left edge). The terminal also prints the plain Neuroglancer URL.

  1. Type a region name, acronym or ID in Find a region, for example locus coeruleus, CA1, substantia nigra or 147. Matching ignores case and accents. It also accepts British spellings (coeruleus finds the atlas's Locus ceruleus) and small typos. Weaker matches are labelled “similar”.
  2. Press Enter for the first match, or use ↑↓ and Enter, or click a result. This happens:
    • only that region is shown, highlighted on its hierarchy level layer;
    • the view jumps to the region and zooms to fit it;
    • its 3D mesh is shown in region meshes;
    • its statistics, and those of the regions that contain it, are pinned in the Selection panel.
  3. Shift+click (or Shift+Enter) adds a region to the highlight, e.g. LC and the subceruleus nucleus together.
  4. Show all regions restores the view as it was before the search. Esc clears the search box.

Side panel: channel LUTs

Each channel, including zoom-stack channels, has:

  • a visibility checkbox;
  • a LUT menu with a preview bar:
    LUTUse
    Grays, Green, Red, Blue, Magenta, Cyan, Yellowblack → colour, as in ImageJ / Fiji; good for overlaying channels
    Fire (hot), Inferno, Magma, Plasma, Viridisperceptually ordered maps to show intensity differences in one channel
    Turbo, Jetrainbow maps with high contrast (not perceptually uniform)
    HiLogrey, with pixels at or below the range minimum in blue and at or above the maximum in red, to check saturation or clipping while setting contrast
  • invert, which flips the LUT.

Changing the LUT keeps the contrast range. You set the range in Neuroglancer: click the channel's layer tab, then Rendering, then drag the range slider or the histogram. Channels 2+ are blended additively, so with e.g. ch1 = Magenta and ch2 = Green, overlap shows white.

Mouse and keyboard

  • Hover to see the region name at every level. The Selection panel (bottom right) shows all statistics of the region under the mouse.
  • Double-click a region to show only that region, add its 3D mesh, and pin its statistics (and those of the regions containing it). Double-click it again to show all regions. Double-click the background to unpin.
  • Ctrl+right-click pins a region without isolating it.
  • In a layer's Seg. tab, search by acronym, name, ID or #tag (e.g. #Isocortex). Per-region statistics appear under “numerical properties”, where you can add them as columns and sort or filter by them.
  • Standard Neuroglancer: scroll to change slice, Ctrl+scroll to zoom, drag to pan, and H for all shortcuts.

7. Region names and atlases

Region names and the hierarchy are taken from the first source found, in this order:

  1. Spinal-cord (Fiederling) atlas: Atlas_Regions.csv next to the manifest's segments_csv.
  2. Allen CCF: parcellation_to_parcellation_term_membership.csv in the config's atlas.atlas_dir, in --atlas-dir, or in ~/atlases/*.
  3. A downloaded BrainGlobe atlas (structures.json) in %BRAINGLOBE_DIR%, ~/.brainglobe or other users' .brainglobe folders (C:\Users\*, /home/*), matched by the config's brainglobe_name.
  4. The sample's own stats/region_stats.csv (region / structure / division).
  5. Bare label numbers.

Better names for BrainGlobe-registered brains (e.g. Perens LSFM). Download the atlas once on the PC to get full names, colours and the complete hierarchy:

uvx --from brainglobe-atlasapi brainglobe install -a perens_lsfm_mouse_20um

Use the name in the sample's config_*.yaml under atlas.brainglobe_name. The next run detects the change and converts again.

8. Zoom stacks

lightsuite-neuroglancer D:\data\brain_atlased --zoom D:\data\brain_multires_results

--zoom takes a LightSuite multires results folder (the one with multires_regopts.json). Each ROI channel becomes a layer at native resolution. The ROIs are placed with the transforms the multires run already saved, so nothing is registered again. Converted zoom data goes to <multires_results>\neuroglancer\ (about 1.15× the raw TIFF size). B-spline elastix stages are not supported. See the README for details.

9. Moved data, other PCs and storage

  • Results moved from Linux to Windows (or another drive): the manifest stores absolute paths such as /media/gbm/NVME2/…. If a path does not exist, the tool looks for the same file name inside the results folder and in volume_registered\sample_space. Copying the whole results folder is enough.
  • Read-only results folder (e.g. a protected network share): the converted data goes to %LOCALAPPDATA%\lightsuite-neuroglancer\ on Windows or ~/.cache/lightsuite-neuroglancer/ on Linux/macOS. You can also set it with --out.
  • Network drives work but the first conversion is slower. Copying the results to a local disk first is faster.
  • The neuroglancer folder can be deleted at any time and is rebuilt on the next run.

10. Troubleshooting

ProblemFix
uv not recognizedReopen the terminal after installing uv. On Windows, check that %USERPROFILE%\.local\bin is in PATH.
lightsuite-neuroglancer not recognizedRun uv tool update-shell and reopen the terminal, or use option A.
“No LightSuite results found”The folder (or the 4 levels below it) has no volume_registered\sample_space\sample_space_manifest.json.
“Annotation volume … not found”The TIFFs listed in the manifest are not in the results folder. Copy them back next to the manifest.
Region names are only numbers or shortNo atlas ontology was found. Install the BrainGlobe atlas (section 7) or pass --atlas-dir.
Blank / black viewerThe browser has no WebGL 2. Use recent Chrome or Edge with hardware acceleration enabled.
Viewer stops loading dataThe terminal was closed. Run the command again (it starts in seconds).
Conversion runs out of memoryClose other programs, or use --no-meshes.
Behind a proxy (first run)Set HTTPS_PROXY before running so uv can download the packages.

The viewer is served only on 127.0.0.1 (this PC). Other computers cannot open the URL. To view a dataset on another PC, install the tool there.
